# 项目初始化

## 执行流程

### 第 1 步：理解需求

先和用户确认：
- 项目名称和用途
- 编程语言和框架偏好
- 是否需要特定的项目结构

如果信息不完整，主动询问。

### 第 2 步：规划项目结构

在开始写代码之前，先用文字描述你计划创建的项目结构：

```
project-name/
├── README.md
├── pyproject.toml (或 package.json / Cargo.toml)
├── src/
│   └── ...
└── tests/
    └── ...
```

让用户确认后再开始创建文件。

### 第 3 步：按顺序创建文件

按依赖顺序创建文件（先建配置文件，再建源码）：

1. **项目配置文件**（pyproject.toml 等）—— 定义依赖和项目元信息
2. **入口文件**（main.py / index.js 等）—— 程序的启动点
3. **核心模块**—— 按架构从底层到上层
4. **README.md**—— 包含项目说明、安装步骤、使用示例
5. **测试文件**—— 基本的单元测试骨架

### 第 4 步：验证

创建完成后，用 `list_directory` 列出项目结构，确认所有文件都已创建。

向用户报告：
- 创建了多少个文件
- 项目根目录路径
- 如何运行项目（具体的命令）
