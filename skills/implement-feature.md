# 功能实现

## 执行流程

### 第 1 步：理解需求

先和用户确认：
- 功能的具体行为和预期结果
- 涉及的文件或模块范围
- 任何技术约束（性能要求、兼容性要求等）

如果信息不完整，主动询问后再开始。

### 第 2 步：阅读现有代码

在动手写之前，先理解相关代码：

1. 用 `list_directory` 了解目标模块的结构
2. 用 `read_file` 读取需要修改或扩展的文件
3. 用 `search_in_files` 查找相关的函数签名、类定义、接口

### 第 3 步：设计实现方案

向用户说明你的实现方案（不要写代码）：
- 需要在哪些文件中做修改
- 新增哪些函数/类
- 修改哪些现有逻辑
- 对现有代码的影响范围

等用户确认后再进入下一步。

### 第 4 步：编写代码

使用 `write_file` 创建或修改文件：
- 遵循项目现有的代码风格和命名规范
- 关键逻辑添加注释
- 处理边界条件和异常情况
- 保持最小改动原则

### 第 5 步：验证

- 用 `read_file` 复读修改后的代码，确认没有遗漏
- 如果有测试文件，提醒用户运行测试
- 给出使用示例
