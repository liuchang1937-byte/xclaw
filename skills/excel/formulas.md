# 公式与缓存

写入公式必须使用显式 `formula` 字段。直接传递以 `=` 开头的字符串按文本保存，防止把源数据误当作公式。
公式使用英文函数名与 Excel 通用分隔符，例如 `=SUM(B2:B10)`。

openpyxl 不提供公式计算引擎。脚本设置工作簿在 Excel 打开时请求重新计算，返回：

```json
{"formulas_calculated": false, "needs_excel_recalculation": true}
```

这不等于已经完成重算。`inspect --data-only` 只能读取文件中现有的缓存值；新生成公式通常返回 null。
修改并保存原有工作簿也可能使公式缓存清空。不要把 null 解释为 0 或声称结果已正确。

核对公式文本、引用范围和输入值；需要验证计算结果时，在用户具备的 Excel/LibreOffice 环境重算。
未获得计算引擎时明确交付“公式已写入、计算待验证”。技能本身不执行宏或外部连接。

CSV 导出把公式作为安全的文本导出，并添加前导单引号；不生成计算结果。
多工作簿 merge 不复制公式行，防止原引用在新工作表中变成错误引用。
