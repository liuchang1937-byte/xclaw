# 子 Agent 任务

在飞书私聊发送一条包含目标和验收要求的消息，例如：

```text
/task 读取工作区里的两份销售表，核对列和合计，生成合并后的 Excel，并把文件发给我
```

一条任务消息也可以带附件。XClaw 会把附件保存到该任务使用的用户工作区，
安排调查、执行和验收，并在完成后发回最终结果。

- `/task status` 查看最近的任务编号。
- `/task status <任务编号>` 查看任务的各步状态。运行中也可以查询。
- `/task resume <任务编号>` 从保存的状态继续。已完成的步骤与已记录的工具结果直接复用。
- `/task retry <任务编号> <步骤编号>` 为失败步骤新建上下文后继续。
  如果提示某个工具的执行结果未确认，先核对已有文件和改动，再显式重跑。

规划器最多安排六个步骤，系统另加最终验收。每个步骤启动独立 Agent，
只接收本步骤指令、相关文件路径和必需的前置结论。实际文件保存在工作区。
最多两个独立的只读步骤并行，修改文件和运行命令的步骤串行执行。
最终验收使用只读工具核对文件和前置证据。附件由服务按验收结果校验、暂存和发送。

任务记录与子 Agent 断点保存在各自会话的私有工作区旁，其他会话只能查询自己的任务。
开启 `agent.isolate_workspace` 时，整项任务使用同一份任务副本，完成后生成变更记录。
