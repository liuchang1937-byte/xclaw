## 验证中修复的问题

起初一个成功样本被引用校验拒收。原因是日志作为 JSON 字符串嵌套时，换行变成字面转义字符，
模型引用真实日志的多行片段无法匹配。现在元数据与原始 stdout/stderr 分开展示，保持原始换行。
另外补充了无效引用的原文、准确来源片段和原输出反馈，帮助有界修复；逐字校验规则没有放宽。
拒收记录仍保留，未把它们记作有效分数。

全部演练和修复共 **14 次模型请求、33,728 个已报告 Token**，包含无效输出。
最终报告复用其中两条通过校验的缓存，仅新增一次请求；报告中的新增用量不代表整次调试总用量。
最终 **3/3 个样本**结构与证据引用有效，已再次按当前证据包复核。
